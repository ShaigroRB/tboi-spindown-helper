# TBOI Spindown helper

This app helps you quickly check if items on the floor can be spindown into an item you are looking for.

## Example

I'm looking for:
- Sacred Heart
- Smelter
- Book of Shadows

And I have these items on the floor:
- IV Bag
- Revelation
- Holy Grail

I can get:
- Smelter via spinning down Revelation
- Sacred Heart via spinning down Revelation or Holy Grail
- Book of Shadows via spinning down IV Bag, Revelation or Holy Grail
